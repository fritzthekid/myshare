CloudWeb for Windows - Installation
=====================================

1) Extract cloudweb.zip anywhere, e.g. to
   C:\install\ (right-click the ZIP file -> "Extract All").

2) In an ADMINISTRATOR PowerShell (Start menu -> "PowerShell" ->
   right-click -> "Run as administrator"), in the extracted folder:

     Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
     .\install.ps1

   Creates: printer "CloudWeb", Windows service "CloudWeb", configuration
   template C:\ProgramData\myshare\backend.env.

3) In a NORMAL PowerShell (without "Run as administrator" - just click
   the PowerShell entry in the Start menu), in the same extracted folder:

     Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
     .\userinstall.ps1

   Sets up the Explorer "Send to" entry "CloudWeb Share" for your own
   user account (deliberately separate from step 2 - an elevated shell
   may run under a different user profile).

4) Enter credentials:

     notepad C:\ProgramData\myshare\backend.env

   Fill in NC_BASE_URL, NC_USERNAME, NC_PASSWORD (Nextcloud app password,
   not the account password) - values WITHOUT quotes! Then:

     Restart-Service CloudWeb

5) Testing:
   - Printing: print any file via the "CloudWeb" printer - link + QR code
     appear automatically at http://localhost:40080/.
   - Sharing: right-click a file in Explorer -> "Send to" ->
     "CloudWeb Share" -> optionally enter a name for password protection.

If there are problems: cloudweb.exe can also be started interactively
instead of as a service (shows log output directly in the window):

     Stop-Service CloudWeb
     C:\ProgramData\myshare\cloudweb.exe
     (stop with Ctrl+C, then: Start-Service CloudWeb)
