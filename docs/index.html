myshare

What is myshare

myshare shares a file via Nextcloud and shows the resulting public link as a QR code - so whoever needs the file can just scan it with their phone, instead of typing a link or waiting for an email.

It started as a CUPS backend (a "virtual printer" that uploads the PDF instead of printing it on paper), and grew into several interchangeable ways to trigger the same upload+share+QR-code flow:

  • Print to a special CUPS queue (from any application with a print dialog).
  • Run a command (sendfile, scripts/share.sh) for an arbitrary file, no printing involved.
  • Upload from a phone (webshare, incl. a Termux build for Android).
  • Drag a file onto "Send to" on Windows (fileshare.exe).

The resulting QR code + link can show up on an attached Raspberry Pi display, in any browser via cloudweb, or just in the terminal log - whichever fits the situation.
